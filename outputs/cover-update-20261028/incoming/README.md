# Design Showcase 作品集 · branch2

基于 card1 v19 的 3D 卡片模板，迁移 branch0 的三个完整案例。直接打开 `index.html`，或双击 `打开作品集.cmd`。无需安装依赖或启动服务器；也可部署到任意静态网站服务。

## 浏览方式

- 第一屏自动展示实体卡片队列，可用顶部按钮暂停；向下滚动、触屏上滑或点击“作品目录”进入第二屏。
- 第二屏左右拖动卡片、使用左右箭头/键盘方向键或圆点切换。三张真实作品可以点击卡片或“查看完整案例”进入详情。
- 三张预留卡仅用于展示位置，不提供详情跳转。
- 每张卡片独立保存摆动状态，左右倾转上限 28°、侧倾上限 12°，松手立即回弹。
- 详情页保留章节导航、流程状态切换、图片放大及录屏；页尾只在三个真实作品间切换。
- 页面底部始终提供三个案例的直接入口。
- 系统“减少动态效果”模式停用队列自动播放与倾转，保留全部切换与导航能力。

## 桌面与移动布局

桌面宽屏采用全宽展示：第一屏左侧身份信息、右侧队列；第二屏左侧卡片、右侧案例介绍与操作。页面最大宽度 1600px，相机视野随真实舞台比例调整。手机使用上方卡片、下方介绍；矮横屏采用左右布局。详情使用最大 1440px 阅读画布并随宽度重排图文。

## 维护入口

- `works.js`：六张卡片的名称、说明、标签、封面和占位状态。
- `assets/covers.js`：为了支持直接双击打开而内嵌的六张封面。封面原文件也在同目录。修改后运行 `node build-covers.cjs` 更新内嵌资源。
- `app.js`：3D 模型、相机、滚动切屏、拖拽与回弹参数。
- `styles.css`：首页各端布局。
- `detail.js`、`detail.css`：三个案例的外层导航与页面布局。
- `cases/`、`media.js`：案例正文、媒体和原站演示交互。
- `build-detail.cjs`：修改详情模块后，用已有 esbuild 包构建 `assets/detail.bundle.js`。浏览网站本身不需要 esbuild。

添加真实作品时，将对应预留项的 `placeholder` 改为 `false`，补齐封面、摘要与详情路由，同时更新详情页的案例注册。不要只改卡面文字就保留空详情。

## 存储与接口

无业务后端、无真实提交或上传。浏览器存储仅保存当前卡片、浏览屏幕、播放偏好和调试视角。三个案例展示原设计中的固定界面与示例流程，不会创建真实订单、聊天或候选记录。

来源：Windows 的 `branch0` 与 `testcode/card1`。两份源网站保持原状，本站独立交付至 `branch2`。

## v2 字体与页面文字调整

主视觉标题改为两行粗体英文 Design / Showcase。移除网站署名及重复的作品统计、分类标签与操作提示；保留案例正文和截图中的示例信息。手机首页项目标题为 32–36px，正文为 14–15px，主要入口为 15–16px，配合提高字重和文字对比。详情页正文排版不变。
