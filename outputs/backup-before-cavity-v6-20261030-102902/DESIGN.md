# Design Showcase 作品集 branch2 设计记录

> 版本：branch2 / 2026-10-28
> 本地交付目录：`outputs/portfolio-branch2-v5/site`
> Windows 交付目录：用户指定的 `branch2` 目录。
> 入口：`index.html`，支持直接打开及静态 HTTP 托管。本次按指定目录交付，没有新增常驻公开服务。
> 内容来源：branch0 的桌崽 AI、研数据、雨浓陪诊；外观与动效来源：card1 v19。

## 项目范围与角色

访客浏览作品、查看完整案例和案例内的固定界面演示。迁移目标为三张真实作品卡和三张明确的预留卡，同时完成桌面、手机、横屏布局。原网站及模板不修改。没有新增身份系统、业务数据库、上传、真实聊天或真实订单处理。

## 功能与页面设计

首页第一屏为自动推进的 3D 队列；第二屏为可拖拽的作品轮播。桌面首屏左侧显示两行主标题，右侧展示卡片；第二屏左侧展示卡片，右侧显示案例说明及入口。手机保留上卡片、下信息的布局，矮横屏改为左右排布。底部始终有三个真实案例直达入口。

三个详情使用独立路由 `detail.html?work=zhuozai-ai`、`detail.html?work=yanshuju`、`detail.html?work=yunong`。案例最大阅读宽度 1440px，保留原模块的图文编排、章节、图片缩放、视频和视图切换；页面外壳统一为米白底和返回导航。

桌崽 AI 与研数据使用已确认的新封面，雨浓陪诊沿用原封面。后三张分别为 04/05/06 预留卡，使用清楚的编号与“暂未添加”状态，不创建示例项目故事、成果或详情。

## 关键交互流程

1. 首屏 → 下滚/上滑/作品目录 → 第二屏。
2. 第二屏 → 拖动、箭头、键盘或圆点 → 切卡；真实卡可进入详情，预留卡只可继续切换。
3. 详情 → 章节导航、视图切换、图片放大/缩放/退出、录屏播放 → 查看内容。
4. 详情页尾只在三件真实作品间切换；返回作品时恢复对应案例。浏览器返回保留该历史页面状态。
5. 第一屏动画可暂停；系统减少动态效果时禁用自动播放、倾转与过渡动画，但导航仍可用。

## 状态设计

- 首页：加载、队列、切屏、浏览、拖动、切卡、回弹、静止。
- 卡片：真实作品、预留占位；占位状态隐藏详情入口并屏蔽主卡跳转。
- 详情：合法项目、无效或占位路由的无详情状态。
- 图片：预览、加载、原图、加载失败；放大弹窗支持缩放和键盘关闭。
- WebGL 异常：显示状态提示，底部案例直达入口仍可操作。

## 交互与数据规则

首页保留 card1 v19 独立卡片弹簧：左右倾转上限 28°、侧倾 12°、辅助俯仰 3°，松手回正与切卡同时开始。新卡有独立的入场角速度。没有共享中心权重传递旧卡姿态，也没有随机俯仰。

相机按真实舞台宽高比调整视锥，保持卡片几何等比。首页与原模板使用独立的浏览/视角存储键。存储仅记录 UI 浏览状态，不保存业务数据。原案例为既有静态设计展示，原有示例业务金额与文字保持来源内容，不等同于真实交易或线上业务。

## 当前差异与限制

本次未重新设计三个案例内部的视觉系统，完整迁移其既有内容与交互。桌崽 AI 和研数据卡面使用已确认的生成封面，雨浓陪诊沿用原封面；本轮未重绘封面或新增业务成果。后三个位置没有作品内容。原站五个虚构或示例项目没有迁移。本次提供静态文件，不涉及互联网域名和线上发布。

## v3 第二屏、高清渲染与表面贴纸

- 第二屏采用 1.12 倍附加正交缩放；视锥、拖动距离及点击投影均使用实际缩放值。
- 桌面舞台由第二屏顶部 16% 调整为 8%，简介由 32% 调整为 25%。手机舞台由 18% 调整为 6%，矮手机由 15% 调整为 4%，简介根据视口和卡片宽度保持间距；横屏仅小幅上移。
- 原生封面纹理为 三张均为 1567×1004，无额外降采样。设备最大各向异性过滤、线性 mipmap 和 1.5–3 倍画布采样，受 400 万像素预算限制。
- 卡面改为不受环境反光与色调映射影响的不透明贴纸材质。玻璃中央承托面与边框最高点齐平，贴纸在承托面前方 0.007 场景单位，图片上方没有透明覆盖层。点击区域投影与贴纸平面一致。
- 保留透明立体边框、三张真实作品及三张预留卡，独立摆动弹簧和详情内容不变。
- 验证覆盖普通屏七组尺寸、高密度手机及 768×1024 平板；检查原生纹理尺寸、像素预算、六卡映射、拖拽、点击、返回、减少动态效果和直接打开文件。

## v5 已确认长阴影与操作更新

- 第二屏：左下方向渐消长阴影，主卡透明度手机 0.16、桌面 0.17，两侧降至主卡的 36%，远离可见邻卡的投影平滑归零。阴影随卡片位移、倾转与相机视角更新。
- 首屏：卡片标题、说明使用右对齐文本，与卡片右缘一致；略收紧说明与卡片的间距，并调整桌面画布顶部渐隐范围以保持文字完整。
- 案例入口：深色胶囊“查看详情”，普通屏高 48px，矮横屏高 40px；保留焦点状态、实际案例链接和占位屏蔽。
- 切屏：地面始终可渲染，使用同一个进度把地面及其接收的投影混合到背景色；关闭地面深度写入，固定渲染顺序。地面淡出区间 0.25–0.88，长阴影淡入区间 0.45–1，均采用连续平滑曲线。返回时使用相同曲线，不引入显隐阈值或延时器。
- 性能：长阴影着色器在启动时预编译，零强度跳过绘制，轮廓采样由预览的 48 次降至 32 次。
- 验证：桌面、手机、矮横屏七组尺寸无脚本异常及横向溢出；六卡映射、拖拽、主卡详情入口、返回定位与减少动态效果通过。桌面和手机共 46 个正反向进度样本验证地面持续存在、渐变权重一致、首个切屏不新增着色器编译。另验证直接双击打开、胶囊入口、详情预览和返回。
