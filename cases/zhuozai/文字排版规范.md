# 作品集文字排版规范

## 桌面详情字号（2026-10-28 · v2.28）

本轮仅在视口宽度不小于 1024px 时生效。移动端及平板原有字号、行高和字重保持不变。

桌崽封面说明为 20px、章节引导为 24px、主要设计说明为 20px、两列说明标题为 26px。研数据封面与章节引导为 20px，概览正文为 18px，偏好说明为 20px、标题为 26px。雨浓封面说明为 22px，章节和功能说明为 20px，角色与匹配规则正文为 18px。研数据与雨浓章节标题在桌面为 36–44px。图片说明、目录及资料来源等辅助文字继续沿用原字号。

保持现有精简文案与功能标题，利用文字层级匹配桌面阅读宽度。密集的 AI 机制参数与组件示例保持现有紧凑排版。CSS 直接由 index.html 加载，本轮不涉及 JavaScript 构建。

## 文案与层级（2026-10-28 · v2.27）

除非用户明确指定，不使用 slogan 式口号、宣传标语或空泛宣言。标题直接标明功能、对象或设计问题；正文说明操作、状态、条件与取舍，由内容、信息层级和结构传达信息。 展示页不叠加同义副标题，不为短句增加独立大字块；正文保持自然换行与原有可读字号。

更新日期：2026-10-22。当前作品一素材为 branch3 v0.4；本轮沿用既有文字层级，不新增字体或改动其他作品排版。

## 参考与采用方式

参考 Apple 中国 [MacBook Air 页面](https://www.apple.com.cn/macbook-air/) 和 [Typography 指南](https://developer.apple.com/design/human-interface-guidelines/typography)。2026-10-15 的参考重点是标题与正文的强弱关系、有限的字体层级、清晰字重和段落留白，不复制产品宣传语或整站视觉。

1440px 视口下的页面抽样：MacBook Air 主宣传语约 64/70px，部分章节标题约 56/60px，介绍段落约 21/29px。这些是当时访问的页面样本，并非 Apple 所有页面的统一标准。指南强调可读性、层级与适合上下文的字重；原生平台 pt 建议不直接作为网页 px 标准。

正文行高 1.75，章节引导 1.65，标题 1.25–1.4。正文重点使用 600 字重。段落优先自然换行，支持时使用 text-wrap: pretty，标题使用 balance。手机单列阅读，不压缩桌面整版文字。

继续使用系统字体栈：macOS 使用本机系统字体和苹方，Windows 使用 Segoe UI 与微软雅黑等可用字体。未下载、嵌入或分发 Apple 字体文件。图片内文字属于原型截图，不受这些 CSS 字号控制，保留点图查看原始大小。

## 内容与空间

- 一章只保留一个主标题和一段引导，删去英文别名与大编号。
- 说明段落集中解释一个设计决定，重点短句可以直接嵌入正文。
- 顺序编号仅表示实际流程；避免为了装饰给每段文字编号。
- 原型演示规则、未实现能力与待验证问题明确保留，不把走查当作用户研究。
- 桌面章节上下留白 96px，中屏 80px，手机 64px；引导文字限制行宽，主要界面可以更宽。
- 保留黄紫配色、真实 UI 和核心状态；移除外层票签、印章、英文小字和重复边框。

本轮 UI 截图统一从 1440 CSS px 宽、DPR 2 的 branch3 v0.4 Web 页面采集，再按实际 DOM 边界裁切。截图内文字属于真实应用渲染，不受作品集正文字号影响；各阅读设备使用同一套 Web 素材，手机端完整等比显示，不换成移动端应用截图，不使用同图重复硬裁。

作品集以 1440 宽 Web 阅读为主要视觉验收环境，检查七章与社区新增内容、图片清晰度和加载、最小字号、长文换行、裁切遮挡、全页横向溢出、目录跟随、共用图片预览和其他作品切换。窄屏检查关注完整等比和控件可达，不把整幅 Web 截图缩小后的字高当作正文 CSS 字号。图片可点击放大；预览内缩放与 Esc 的行为沿用 media.js。

默认可见文字字符数不包含图片中的文字，折叠补充内容也不计入；因此字符数减少代表正文编排精简，不代表删除了同等比例的产品内容。
