# 作品集文字排版规范

更新日期：2026-10-15。

## 参考与采用方式

参考 Apple 中国 [MacBook Air 页面](https://www.apple.com.cn/macbook-air/) 和 [Typography 指南](https://developer.apple.com/design/human-interface-guidelines/typography)。本次重点学习标题与正文的强弱关系、有限的字体层级、清晰字重和段落留白，不复制产品宣传语或整站视觉。

1440px 视口下的页面抽样：MacBook Air 主宣传语约 64/70px，部分章节标题约 56/60px，介绍段落约 21/29px。这些是本次访问的页面样本，并非 Apple 所有页面的统一标准。指南强调可读性、层级与适合上下文的字重；原生平台 pt 建议不直接作为网页 px 标准。

## 本项目的字号

| 用途 | 桌面 | 手机 | 字重 |
| --- | --- | --- | --- |
| 案例主标题 | 64–96px | 56–64px | 600 |
| 章节标题 | 48px；中屏 42px | 32px；320px 窄屏 30px | 600 |
| 章节引导 | 22px | 20px | 400 |
| 内容标题 | 24–36px | 24–28px | 600 |
| 正文 | 18px | 17px | 400 |
| 图片说明、补充状态、项目范围 | 16px | 16px | 400–500 |
| 目录与次要控件 | 14px 起 | 14px 起 | 400–500 |

正文行高 1.75，章节引导 1.65，标题 1.25–1.4。正文重点使用 600 字重。段落优先自然换行，支持时使用 text-wrap: pretty，标题使用 balance。手机单列阅读，不压缩桌面整版文字。

继续使用系统字体栈：macOS 使用本机系统字体和苹方，Windows 使用 Segoe UI 与微软雅黑等可用字体。未下载、嵌入或分发 Apple 字体文件。图片内文字属于原型截图，不受这些 CSS 字号控制，保留点图查看原始大小。

## 内容与空间

- 一章只保留一个主标题和一段引导，删去英文别名与大编号。
- 说明段落集中解释一个设计决定，重点短句可以直接嵌入正文。
- 顺序编号仅表示实际流程；避免为了装饰给每段文字编号。
- 原型演示规则、未实现能力与待验证问题明确保留，不把走查当作用户研究。
- 桌面章节上下留白 96px，中屏 80px，手机 64px；引导文字限制行宽，主要界面可以更宽。
- 保留黄紫配色、真实 UI 和核心状态；移除外层票签、印章、英文小字和重复边框。

## 验证范围

以本地 Chrome 的 file:// 页面检查 1440、1024、390、320px；检查八章可见性、图片加载、正文最小字号、细字重、横向溢出、目录导航、图片查看器、历史路由和其他作品切换。Windows Chrome 再检查实际中文字体渲染。记录位于 outputs/typography-20261015/。

默认可见文字字符数不包含图片中的文字，折叠补充内容也不计入；因此字符数减少代表正文编排精简，不代表删除了同等比例的产品内容。
