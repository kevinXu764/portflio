## 截图与事实边界

- 当前展示源为 Windows 原项目中的 `桌崽AI/branch3` v0.4。branch2 只保留为历史来源，不再作为当前 UI 素材。截图必须实际加载 HTML、字体和图片后采集，不以生图替代界面。
- 统一视口为 1440 CSS px 宽、DPR 2。整页图保留完整布局，局部图依据实际 DOM 裁切；`captures.js` 同步记录逻辑尺寸和 `density: 2`，更新对应轻量预览，旧的标注坐标不能直接复用。
- 画面中的角色、消息、事件、作者、播放量、点赞量、作品与记忆均为固定演示样例，不是真实用户数据。作品集的截图和浏览器走查不构成用户研究或线上成效。
- 文字与视频切换复用同一消息面板和输入节点，可以保留当前未发送文字；跨路由不持久保存聊天草稿。“继续草稿”与首次“小芽”问候是预置状态，不代表将用户本次表单创建为业务角色。
- 语音只展示固定转写样例，用户确认后进入可编辑草稿；没有申请麦克风权限或执行真实识别。通话使用插画与固定状态，不接入真实音视频。
- 事件 40/68/85、剩余回应 3/2/1、成功 +6 和暂缓不变为预设结果。当前不按输入计算进度或亲密度，不真实扣减、退还或充值电量。此前的限次、关键词加分、负面输入与冷却规则只作为目标产品方案留档，不当成当前已实现机制。
- 保存、创建、收藏、删除提供固定反馈，不改变业务记录，不使用浏览器或服务端业务存储；本地图片仅在当前表单临时预览。剧场是六句插画对白预览，社区是四个固定作品的筛选与回放，没有真实发布、推荐或互动接口。
- 桌面陪伴在网页画布内显示，人物与粉色控制器同组移动；不是操作系统桌宠。暂停、隐藏和收起展示当前 UI 状态，不声称实现原生系统悬浮能力。
- 原作品提供“多轮后容易忘记角色生气原因”的观察，但没有样本或原始研究记录，不把它写成已验证的普遍结论。未代填作者职责、项目周期、团队分工或线上成果。
